# அஷ்டாதச ரஹஸ்யம் · Ashtadasa Rahasyam

A digitized, searchable Tamil e-book of **Ashtadasa Rahasyam** (the eighteen rahasyas of
Piḷḷai Lokācāryar), produced from a 652-page scanned edition.

## What's here
- `index.html`, `styles.css`, `app.js` — a self-contained reflowable e-book reader
  (visible contents index, light/sepia/night themes, font controls, full-text search,
  original-scan lightbox, reading progress + resume).
- `data/book.js` — cleaned OCR text for all 652 pages plus the chapter table of contents.
- `pages/` — full scanned page images (`page-001.jpg` … `page-652.jpg`).
- `thumbs/` — thumbnails.
- `Ashtadasa-Rahasyam.epub` — downloadable EPUB3 (Apple Books / Kindle / any e-reader).

## Use
Open `index.html` in any modern browser. No server required.
To host on GitHub Pages, enable Pages for this branch; the site root is this folder.

## Note
Text is from OCR of an old Tamil print edition, so it is highly readable but not flawless;
each page has a "view original scan" button for verification.
